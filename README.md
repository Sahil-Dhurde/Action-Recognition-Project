# Action Recognition Using Python

## Overview

This project implements Human Action Recognition using Computer Vision and Machine Learning/Deep Learning techniques. The system analyzes video input and identifies human actions such as walking, running, jumping, waving, sitting, and other activities.

The project can process live webcam feeds or prerecorded videos and predict the performed action in real time.

---

## Features

- Human action detection from videos
- Real-time action recognition using webcam
- Support for multiple action classes
- Data preprocessing and feature extraction
- Model training and evaluation
- Prediction visualization with action labels
- Easy-to-use Python implementation

---

## Technologies Used

- Python 3.x
- OpenCV
- NumPy
